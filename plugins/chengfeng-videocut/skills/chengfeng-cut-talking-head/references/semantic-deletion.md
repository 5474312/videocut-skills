# 语义删除规则

## 最高原则

```text
前一次不完整 / 错误表达  -> 删除
后一次完整 / 正确重说    -> 保留
```

默认删前保后。不要用“较短的一句”替代这个顺序规则，除非用户明确指定保留前版。

## 判断之前：稿子必须按播放顺序铺平

**这是识别质量最大的单一变量，比判据本身更要紧。**

判断「有没有重复」靠的是前后相邻，而相邻指的是**播出来相邻**，不是文件里存着相邻。剪过的项目里，
源片上隔 40 秒的两句话在成片里可能紧挨着；源片上紧挨着的两句中间可能还留着内容。

**必须用 Product 提供的视图，不许自己拼：**

```bash
node "$VC" transcript playback "$jobDir" --json
```

它按播放顺序铺平成一条流，`removedSpeech` 标出此处原本说过话、已删除、不会播出。
返回里的 `note` 字段是这份输入的读法，判断前先读它。

**为什么不许自己拼**（2026-07-26 实测，两次都拼错了）：

```text
错法一   按原始段落分组、保留原始段号
         剪过之后段号必然跳号（0121 -> 0124），判断者把跳号读成
         「中间有 3.47 秒没给我看，所以不能判」——而那 3.47 秒正是已删内容
         后果：两条正确判断被否决，其中一条是一眼可见的重复

错法二   把被压掉的停顿也标成「此处删过内容」
         标记从 15 个涨到 58 个，判断者以为整篇到处断裂
         后果：普遍变保守、宁可不删
```

两次的共同点：**判据没错，输入撒了谎，而且是静默的。** 输入格式改变的是结论，不只是呈现。

## 候选类型

- 句间重复：两次表达同一意思，删除前一次。
- 句内重复：只删前面的重复片段，保留后续完整句，不能顺手删整句。
- 残句与改口：删除前面的残句、错误数字或错误专名，保留完整重说。
- 英文卡壳：识别英文词头、字母或音节重复，不只匹配中文。
- 语气词：单个自然语气词保守保留；连续无意义语气词可作为一组低风险候选。
- 有口播稿：只用于语义对齐与纠错，不能逐字 diff，也不能补入视频没说的话。

## 风险

| 风险 | 例子 | 动作 |
| --- | --- | --- |
| 低 | 完全包含的前置重复、三字以内连续口头禅 | 可初始化为删除 |
| 高 | 整句、长片段、同开头但后半分叉、专名或数字改口 | 必须复核上下文，见下 |

**「复核上下文」是 AI 自己再看一遍，不是拿去问用户。**

高风险只改变**判断要多严**，不改变**结果长什么样**。复核的做法是回到播放顺序的稿子把前后念一遍、
确认删的是靠前那一版、确认删完读得通；确认不了就**不列为候选**。

删除只有「删除 / 未删除」两态。高风险候选不得变成「建议删除，等用户点头」——那是第三态，
产品已明确否决。人的审核发生在**提交之后**：用户在文稿上看划线，自己决定恢复哪些。

```text
不要   逐条问用户「这条要删吗」
不要   把候选标成「待确认」交上去
要     自己复核完，该删的直接进 cutWordIds，不该删的丢掉
```

## 提交：每次交完整结论，不是增量

`cuts set` 的语义层是**替换**语义，不是累加：Product 用「停顿基线 ∪ 本次提交」重建删词集合。
所以提交里必须包含**本轮判断的全部结论**，不只是这一轮新找到的。

2026-07-26 实测的后果：第二次只交了新找到的两处，上一轮四处的记录被挤掉，删词数从 430 掉到 394。
声音仍然正确（手工时间线只会被挖、不会被恢复），**但账本退了，而且 `changed: true` 看着一切正常**。

`cuts set` 现在会在结果里报 `noLongerCut`——本次不再删的词数与样本。**提交后必须看这个字段**：
不为零且不是有意撤回，就是交了增量。

每个候选都绑定稳定 `wordIds`、类型与风险；不要用数组位置、文本行号或时间近似替代 wordIds。

## 理由会被记下来

`reasons` 已经落盘（2026-07-26 起）：每组词带 `kind` 与 `risk`，存在 Cuts 里。

两条性质由 Product 保证，Skill 不用自己维护：

- 理由不会比它解释的删除活得久——词被恢复，理由自动消失
- 理由里提到没被删的词，那部分会被裁掉；形状不合法直接报错

所以理由要如实写。**界面目前不显示它**，但它是「为什么删这一句」唯一的记录。

## 静音边界

普通静音不是语义删除候选。相邻 gap 的合并和停顿压缩由 Product 的 `natural-pause-v2` 处理；Skill 不运行自然停顿脚本，也不让多个相邻静音区间重复累积。
